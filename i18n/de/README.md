> **AI bedeutet Liebe.**
> Im Chinesischen wird „AI" genau wie 愛 ausgesprochen — das Wort für *Liebe*. Wir zeichnen jeden Schritt der künstlichen Intelligenz auf, weil wir glauben, dass sich ihr Fortschritt daran misst, wie sie Menschen hilft, heilt und verbindet.

Eine lebendige, überprüfbare **Chronik der KI-Geschichte**: zuerst vom Turing-Test 1950 bis heute aufgefüllt, danach **jeden Tag um einen sorgfältig geprüften Eintrag** ergänzt. Kein Hype, keine erfundenen Geschichten — nur das Protokoll einer Welt, die voranschreitet, Tag für Tag.

## Was dieses Projekt tut

1. **Eine überprüfbare Chronik** — die Datei `TIMELINE.md` in diesem Ordner
   Jeder Eintrag enthält Datum, was geschah, **warum es wichtig ist — das Gute, das es bringt** — und Quellen. Daten sind tagesgenau, wenn sie überprüfbar sind; sonst wird nur der Monat angegeben. Nichts wird erfunden.
2. **Strukturierte Daten** — `data/events.json`
   Dieselbe Geschichte in maschinenlesbarer Form, bereit für eine visuelle Zeitstrahl-Website, Diagramme, Videos und tägliche Zusammenfassungen.
3. **Ein Eintrag pro Tag** — `daily/YYYY-MM-DD.md`
   Jeden Tag wählen wir das eine Ereignis, das es am meisten verdient, erinnert zu werden. Qualifiziert sich keines, schreiben wir ehrlich „heute kein Eintrag" und begründen es.

## Was einen Platz in der Geschichte verdient

✅ Wichtige Modell- oder Produktstarts, Meilenstein-Paper, große Open-Source-Veröffentlichungen, wissenschaftliche Durchbrüche (Medizin, Proteine, Barrierefreiheit …) sowie Politik- und Governance-Ereignisse mit breiter Wirkung
❌ Gerüchte, reines Marketing, eintägige Börsenbewegungen, unbelegte Behauptungen

Jeder Eintrag verlangt **zuerst eine offizielle Quelle plus mindestens eine unabhängige Quelle** zur Gegenprüfung. Siehe `docs/DAILY_UPDATE.md` und die Mehrsprachigkeitsregeln in `docs/I18N.md`.

## Der Name

- **AI** klingt wie **愛 (Liebe)**: Technik zum Guten ist hier kein Slogan — sie ist die letzte Spalte jedes Eintrags: *Wie macht das das Leben der Menschen besser?*
- Das unterscheidet diese Chronik von einer bloßen Zeitleiste: Sie hält nicht nur fest, was geschah, sondern was es für gewöhnliche Menschen bedeutet.

## Mitmachen

Ein falsches Datum, ein fehlender Meilenstein oder eine bessere Quelle? Eröffne ein Issue oder einen PR mit Datum, Quellenlink und einem Satz Erklärung.
