# 每日更新机制 · DAILY UPDATE

## 节奏

- **每天 1 条，21:00（Asia/Shanghai）前完成**当日一记；没有够格的事件就写「今日无收录」，不凑数。
- 流程：全天候选收集 → 按收录标准筛选 → 双来源核查 → 写 `daily/YYYY-MM-DD.md` → 同步追加 `TIMELINE.md` 与 `data/events.json` → 提交 Git（commit 信息：`daily: YYYY-MM-DD <事件标题>`）。

## 收录标准（五选一即可，但必须可核查）

1. 重要模型 / 产品正式发布（有官方公告）
2. 里程碑论文或科学发现（医疗、蛋白质、数学、无障碍等优先——「爱」的栏目）
3. 重大开源（权重、框架、数据集）
4. 影响广泛的政策、法规、司法或行业治理事件
5. AI 大规模造福人的落地案例（有真实数据支撑）

不收：传闻、二手转述无源头、纯营销、单日股价/市值波动、重复旧闻。

## 核查规则

- 日期以**事件发生/官方发布日**为准，精确到日；时区差异导致日期差一天的，注明来源时区。
- 官方来源优先，其次权威媒体；两处说法冲突时，以官方为准并注明分歧。
- 数字（参数量、用户数、金额）必须能在来源中直接找到，找不到就不写。

## 每日一记模板

```markdown
# YYYY-MM-DD · <事件标题>

- **日期**：YYYY-MM-DD
- **类别**：发布 / 论文 / 开源 / 政策 / 向善落地
- **主角**：<公司/机构/团队>

## 发生了什么
（2–4 句，只写已核实的事实）

## 为什么值得被历史记住
（2–3 句：它改变了什么）

## 它带来的善
（1–2 句：对普通人、患者、学生、开发者……具体的好处；没有就不硬凑，写「待观察」）

## 来源
- 官方：<链接>
- 独立报道：<链接>
```

## 多语言同步（2026-10-26 起）

- 项目共 10 种语言，**英文为源语言（canonical）**，规范见 `docs/I18N.md`。
- 每日一记定稿顺序：先写英文主版（根目录 `TIMELINE.md` + `daily/`），同日同步简中（`i18n/zh-CN/`）；繁中由简中转换并校对；日语、韩语尽量同日同步。
- 给维护者的审稿稿用中文呈现，但发布以英文主版为准。
- 西/法/德/葡/俄的时间线全译完成前，其 `TIMELINE.md` 保持「翻译进行中」的如实标注，不冒充完成。
