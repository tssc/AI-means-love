## 发生了什么

LG AI Research 在首尔 COEX 举行的 NVIDIA AI Day Seoul 2026 上宣布：自家主权 AI 基座模型 K-EXAONE 2.5 的 API 即日起通过 EXAONE API Platform（docs.exaone.ai）免费向所有人开放。开发者、初创公司、企业与研究机构只需领取一个 API 密钥，即可零成本把模型用于服务开发与研究。

K-EXAONE 2.5 总参数 750B、每 token 激活 31B，纯文本、支持韩语与英语，上下文 512K token（524,288），知识截止 2026 年 1 月，接口与 OpenAI 兼容（模型名 `k-exaone_v2.5`），支持工具调用、结构化输出与代码生成。它是 8 月发布的韩国主权 AI 项目第二代模型 K-EXAONE 2.0 的追加训练版，LG 自称「技术验证模型」——验证出的训练技术将用于第三代模型，目标是 2027 年 1 月前完成前沿级 EXAONE 模型。

LG 官方口径的智能体基准（均为内部自测，未经独立复现）：SWE-Bench Pro 59.21 分、BrowseComp 78.0 分、AutomationBench 开放集 74.6 分、Claw-Eval 77.29 分；与 DeepSeek-V4.1-Flash 和 GLM-5.3 对比，K-EXAONE 2.5 在其中三项上超过前者、在其中一项上超过后者。LG 称 24 项评测的综合表现较 8 月模型提升 70% 以上。LG 同时表示正考虑采用 NVIDIA Dynamo 技术提升推理效率，NVIDIA 此前已发布针对 K-EXAONE 优化的 Dynamo 使用指南。

## 为什么值得被历史记住

这是韩国主权 AI 计划第一次把旗舰模型交到所有人手里——不是论文、不是演示、不是限量内测，而是 750B 参数的模型免费可用。一个国家级 AI 项目的成果从实验室变成了公共基础设施：任何韩国开发者都能直接调用与中国前沿开源模型同一档的智能体能力，去写代码、做搜索、自动处理日常工作。这也是「开放」的第三种形态：既不是开源权重（Kimi、Mistral 的路），也不是收紧许可（百度的路），而是「模型闭源、调用免费」——能力免费流通，权重仍握在自己手里。LG 把这次开放定位为通往 2027 年 1 月前沿级模型的跳板，韩国主权 AI 的竞赛至此有了明确的时间表。

## 它带来的善

从今天起，韩国的开发者、学生团队与小公司不用付 API 账单就能用上 750B 级模型做编程、文档分析与工作自动化——前沿能力不再只属于付得起钱的大公司。但须保留提醒：模型只支持韩语与英语、纯文本，且免费期限与额度未公布，「免费」能持续多久要看 LG 后续的安排；全部基准均为 LG 自报，未经独立复现。

## English version (canonical)

# 2026-11-09 · LG opens the K-EXAONE 2.5 API for free: Korea's 750B-parameter sovereign model for everyone

- **Date**: 2026-11-09
- **Category**: Release
- **Protagonist**: LG AI Research

## What happened

At NVIDIA AI Day Seoul 2026, held at COEX in Seoul, LG AI Research announced that the API for K-EXAONE 2.5, its sovereign AI foundation model, is free for everyone from today, through the EXAONE API Platform (docs.exaone.ai). Developers, startups, companies and research institutions need only obtain an API key to use the model for service development and research at no cost.

K-EXAONE 2.5 has 750B total parameters with 31B active per token. It is text-only, supports Korean and English, and offers a 512K-token context (524,288 tokens) with a January 2026 knowledge cutoff, through an OpenAI-compatible interface (model name `k-exaone_v2.5`), with tool calling, structured outputs and code generation. It is a further-trained version of K-EXAONE 2.0, the second model of Korea's sovereign AI project released in August 2026 — LG calls it a "technology-validation model": the training techniques it validates will feed the third-generation model, with the goal of a frontier-level EXAONE model by January 2027.

Company-reported agentic benchmarks (LG's own measurements on open datasets, not independently reproduced): 59.21 on SWE-Bench Pro, 78.0 on BrowseComp, 74.6 on AutomationBench open-set and 77.29 on Claw-Eval. Against DeepSeek-V4.1-Flash and GLM-5.3, K-EXAONE 2.5 scores above the former on three of the four and above the latter on one. LG says overall performance across 24 evaluation metrics improved by more than 70% against the August model. LG also says it is considering NVIDIA Dynamo to improve inference efficiency; NVIDIA has previously published a Dynamo guide optimized for K-EXAONE.

## Why it matters

This is the first time Korea's sovereign AI programme has put its flagship model in everyone's hands — not a paper, not a demo, not a limited preview, but a 750B-parameter model free to use. A national AI project's output becomes public infrastructure: any Korean developer can directly call agent capability in the same class as China's frontier open models, to write code, search the web and automate everyday work. It is also a third shape of openness: neither open weights (the Kimi and Mistral route) nor a tightened licence (the Baidu route), but "closed weights, free calls" — capability circulates for free while the weights stay in-house. LG frames the opening as a springboard to a frontier-level model by January 2027, giving Korea's sovereign AI race a dated finish line.

## The good it brings

From today, Korean developers, student teams and small companies can use a 750B-class model for coding, document analysis and workflow automation without paying an API bill — frontier capability no longer belongs only to companies that can afford it. Two caveats stay attached: the model supports only Korean and English, text only, and neither the duration of the free period nor any usage quota has been disclosed, so how long "free" lasts depends on LG's later decisions; and every benchmark figure is LG's own, not independently reproduced.
