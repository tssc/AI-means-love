## 发生了什么

美团技术团队 11 月 2 日宣布发布 LongCat-2.5，一款面向长程智能体任务的原生多模态模型，是 2026 年 6 月 LongCat-2.0 的后续正式版（9 月 25 日曾先行上线预览版）。美团口径：模型总参数量 1.6 万亿，每个 token 激活约 480 亿参数；在 LongCat-2.0 基础上强化原生视觉理解与智能体编程能力。

「原生多模态」有具体含义：模型把视觉信号表示为多层级离散 token，使主干模型以统一的 token 形式处理视觉与文本输入，而不是外挂视觉编码器再拼接特征。结合之后，模型可用于看图编程、创意设计与 3D 相关任务。训练侧：长序列训练中加入更多长程轨迹数据，并通过大规模长程强化学习提升复杂代码库开发、完整项目构建等任务的端到端工程能力；真实 Agent 的失败轨迹被转化为可复现、可验证的训练任务，针对能力短板补数据。基础设施侧：优化国产算力上的长上下文训练与 W4A4 推理（专家权重与激活同时量化至 4 比特）；据美团口径，训练全程由国产算力完成。

可用性须如实说明：模型已在官网 LongCat.ai 提供在线体验并同步上线 API，兼容 OpenAI 与 Anthropic 协议，可接入 Claude Code、Codex 等智能体工具；但 GitHub 与 Hugging Face 权重发布仅标注「敬请期待」，未给日期——本次为 API 优先发布，与 2.0 上线五天即 MIT 开源权重不同。美团自测成绩（未经独立复现）：Terminal-Bench v2.1 为 88.4，高于 2.0 的 70.8。

## 为什么值得被历史记住

智能体时代的标尺正在从「答对一道题」转向「独立干完一个长活」：LongCat-2.5 的定位就是横跨代码库、终端、浏览器、表格与设计工具，持续执行直至交付完整项目。它也是中国模型在受限硬件条件下冲击前沿智能体能力的一个样本——万亿参数规模、全程国产算力训练、推理侧压到 4 比特，证明「国芯国模」路线可以支撑长程智能体任务，而不只是一个参数数字。同时它的发布方式本身值得记录：先预览、后正式，API 先行、权重待定，开源与否不再是发布当天的默认动作。

## 它带来的善

开发者和小团队多了一个能「看图干活」的长程帮手：给它一张设计稿或一段界面截图，它能接着写代码、改代码库、搭完整项目，而不必把大任务拆成一句句对话；商家侧，美团已基于 LongCat 系列推出 AI 经营工作台「妙手」，在商家授权范围内帮商家理解经营指标并执行经营任务。但权重未放出之前，普通开发者只能通过 API 使用，数据须经美团服务，自托管与离线使用仍待观察。

## English version (canonical)

# 2026-11-02 · Meituan releases LongCat-2.5: natively multimodal, built for long-horizon agent tasks

- **Date**: 2026-11-02 (Beijing reporting date; the official tech blog is dated Nov 1 per a German secondary citation, and the API changelog entry is dated Nov 2 — a one-day gap from time zones / release sequencing, noted here)
- **Category**: Release
- **Protagonist**: Meituan LongCat team

## What happened

On November 2, Meituan's technical team announced LongCat-2.5, a natively multimodal model for long-horizon agent tasks — the formal release following LongCat-2.0 (June 2026) and a preview that went live on the API platform on September 25. Meituan's figures: 1.6 trillion total parameters, about 48 billion activated per token, with stronger native visual understanding and agentic coding than LongCat-2.0.

"Native multimodality" has a concrete meaning here: visual signals are represented as multi-level discrete tokens, so the backbone model processes vision and text in one unified token form rather than bolting on a vision encoder. Combined with agentic coding, the model supports visual coding, creative design and 3D tasks. On training, Meituan added more long-trajectory data and used large-scale long-horizon reinforcement learning to improve end-to-end engineering on complex codebases and complete projects, and turned real agents' failure trajectories into reproducible, verifiable training tasks. On infrastructure, it optimized long-context training and W4A4 inference (weights and activations both quantized to 4 bits) on domestic compute; Meituan says training ran entirely on domestic chips.

Availability must be stated plainly: the model is live on longcat.ai and via API, compatible with OpenAI and Anthropic protocols and usable inside tools such as Claude Code and Codex — but GitHub and Hugging Face weight releases are marked "coming soon" with no date. This is an API-first release, unlike LongCat-2.0, whose weights went up under MIT five days after launch. Meituan's own benchmark figure, not independently reproduced: 88.4 on Terminal-Bench v2.1, up from 70.8 for LongCat-2.0.

## Why it matters

The agent era's yardstick is shifting from "answer one question right" to "finish a long job alone": LongCat-2.5 is positioned to work across a codebase, a terminal, a browser, a spreadsheet and a design canvas until a whole project is delivered. It is also a sample of Chinese models chasing frontier agent capability under hardware constraints — trillion-parameter scale, trained entirely on domestic compute, inference squeezed to 4 bits — showing the domestic-chip-plus-domestic-model route can carry long-horizon agent work, not just a parameter count. Its release pattern is itself worth recording: preview first, formal release second, API first, weights pending — open weights are no longer the default move on launch day.

## The good it brings

Developers and small teams gain a long-horizon helper that can "see and work": hand it a design mockup or a UI screenshot and it can write code, edit a codebase and build a complete project without the task being chopped into one prompt at a time. On the merchant side, Meituan has built an AI operations workbench ("妙手") on the LongCat family that, within merchant authorization, helps merchants read business metrics and carry out operations tasks. Until weights are released, however, ordinary developers can only use it through the API, with data passing through Meituan's service — self-hosting and offline use remain watch-and-wait.
